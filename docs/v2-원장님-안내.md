## 페이지별 설명

### 1. 대시보드 (첫 화면)

접속하자마자 뜨는 오늘 요약 화면이에요.

- **큰 날짜**와 함께 오늘 충전받은 금액 / 차감한 금액이 두 카드로 표시
- 아래 **Recent Activity** — 방금 다녀간 손님이 시간순으로
- 상단 **[오늘 · 이번 주 · 이번 달 · 전체]** 로 기간 바꿔볼 수 있어요

### 2. 매출

정액권 판매까지 포함한 매출 리포트예요.

- **판매 금액** = 손님이 실제로 낸 돈 (세금 신고할 매출)
- **잔액 적립 총액** = 손님이 앞으로 쓰실 돈 (돌려드릴 돈)
  - 회색 배경으로 몇 % 소진됐는지 보여줘요
- **보너스 비용** = 정액권 할인으로 나가는 순수 마케팅 비용
- **판매 건수 · 활성 회원** — 이 기간 오신 손님 통계
- **일자별 판매 그래프** · **등급별 도넛 차트** (20/30/50만원 어떤 게 잘 팔리나)
- **TOP 회원** · **최근 판매 이력**
- 아래에 **이번 달 만료 예정 정액권** · **60일 이상 안 오신 손님** 알림

**NEW · 기간 지정** — 위쪽 pill 옆의 [기간 지정] 누르면 날짜 두 개 골라서 원하는 구간만 볼 수 있어요.

### 3. 회원 관리

손님 리스트예요. 잔액 많은 손님이 위로.

- **검색창**에 이름 or 전화번호 앞자리 넣으면 바로
- 우측 상단 **[신규 회원]** 으로 새 손님 등록
  - 전화번호 자동 하이픈, 카드 UUID 자동 생성 버튼

### 4. 회원 상세 (한 명 카드)

리스트에서 손님 눌러서 들어가는 화면.

- **잔액**이 가장 크게
- 아래 **총 충전 / 총 차감** 두 줄
- **메모** — 특이사항 · 선호 디자이너 등 자유롭게 (수정 버튼)
- **최근 거래** 시간순 리스트
- 우측 위 **[충전] [차감]** 버튼으로 바로 진행
- 페이지 맨 아래 **[회원 삭제]** — 실수 방지로 확인 팝업 있음

### 5. 충전 (모달 팝업)

[충전] 누르면 뜨는 화면이에요.

- **6장의 정액권 카드** (20/30/50만원 × 카드/현금) 중 하나 클릭
- 또는 아래 **기타 금액**에 자유롭게 입력해서 정액권 없이 충전

**NEW · 확인 화면** — 카드 누른다고 바로 차감되지 않아요. "이대로 진행할까요?" 확인 화면이 슬라이드로 넘어가고, [충전 확정] 눌러야 저장. 실수로 두 번 눌러도 한 번만 충전돼요.

### 6. 차감 (모달 팝업)

[차감] 누르면 뜨는 화면이에요.

- 프리셋 금액 버튼 (**20,000 / 23,000 / 25,000 / 44,000 / 55,000**) 하나 클릭하면 자동 입력
- 아니면 위쪽 입력창에 직접 금액 입력
- **시술 태그** (컷 / 펌 / 매직 / 클리닉 / 염색 / 뿌리염색) 눌러 메모 자동 채움
- 다음 → 확인 화면 → [차감 확정]

### 7. 설정 · 충전 보너스

정액권 상품 6종을 관리하는 화면이에요.

- 각 상품마다 **판매가 / 적립금액 / 보너스 / 증정품** 표시
- **[편집]** 으로 가격이나 증정품 변경
- **[비활성화]** 로 잠시 판매 중단 (기존 판매 이력은 그대로 보존)
- **[+ 새 상품 추가]** 로 새 등급 추가

### 8. 설정 · 차감 금액

차감할 때 뜨는 프리셋 금액을 관리해요.

- 왼쪽 **손잡이(≡)** 를 잡아 끌어 순서 조정
- [편집] / [비활성화] / [삭제] / [+ 새 금액 추가]

### 9. 설정 · 시술 메모

차감할 때 옆에 뜨는 시술 이름 태그를 관리해요.

- 매장에서 자주 쓰시는 시술 이름으로 자유롭게 편집
- 순서도 드래그로 조정 가능
